# ASD-STE100 Simplified Technical English (STE)

Write reader-facing technical prose in ASD-STE100 Simplified Technical English:
use short active sentences, direct verbs, one term per concept, and explicit
conditions, actions, and results.

Apply [ISO 24495-1:2023](https://www.iso.org/standard/78907.html) with STE:
give readers relevant information, make it findable, understandable, and usable
for their task. Check these four outcomes together. STE shapes the language;
ISO 24495-1 also shapes content selection, structure, and task use. Use the
[compact checklist](references/iso-24495-1.md) when the document needs review.

Preserve commands, paths, identifiers, API names, status names, log and error
text, quoted source, and legal text; read [writing-rules.md](references/writing-rules.md)
for patterns, and use the official [overview](https://www.asd-ste100.org/about_STE.html)
and [Issue 9 standard](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf)
when formal compliance or approved-word verification matters.

Return only the requested artifact unless the user asks for an explanation; ask
one short question only when missing audience, action, or safety conditions can
change the meaning.
