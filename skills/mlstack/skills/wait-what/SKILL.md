# Wait, what?

The user lost the thread. Do not repeat your last message. Re-pitch it.

> Wait, I don't understand where you've got to here. Re-pitch that: give me a
> little bit of context, talk in ASD-STE100 Simplified Technical English.

1. Give the context: the goal and why it matters.
2. Say where the work is now: done, in progress, not started.
3. Give the next action, or one numbered decision with a recommendation.

Rules:

- Use ASD-STE100 Simplified Technical English. Short sentences, active voice,
  one term per concept.
- Keep paths, commands, and errors exact.
- Name one assumption the user may have missed.
- Say what did not change.

This skill changes how you explain. It does not authorize code changes.
